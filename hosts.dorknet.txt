# Append this entire block to the bottom of:
#     C:\Windows\System32\drivers\etc\hosts
#
# Open Notepad as Administrator (right-click → Run as administrator), File →
# Open → set the file-type filter to "All Files (*.*)", navigate to
# C:\Windows\System32\drivers\etc\, pick `hosts`, paste, save.
#
# After saving, flush the resolver cache so Windows picks up the changes:
#     ipconfig /flushdns
#
# Replace 127.0.0.1 with your server's LAN IP (e.g. 192.168.1.50) on every
# line if you're hosting for other machines on your network. Each client
# machine needs its own copy of these entries pointing at the server's IP.
#
# Why every subdomain is listed individually: the Windows hosts file (and
# /etc/hosts on Linux/Mac) does NOT support wildcards. *.rec.net won't work.
# If you want true wildcard resolution, install Acrylic DNS Proxy on Windows
# or dnsmasq on Linux instead — but the explicit list below is sufficient
# for a single-host setup.
#
# Every entry below corresponds to a [Host("xxx.rec.net")] controller in
# DorkNet.Server, plus a few subdomains the client sometimes hits that
# fall through to GlobalCatchAllController.
